# قالب برومبت سريع للوكيل

انسخ هذا في محادثة Cursor لتفعيل مسار الفيديو → مراجعة → خطوات.

---

## طلب تصوير جديد

```text
استخدم skill: iphone-mobile-video-agent

أبي فيديو لتطبيقي على الآيفون.

الفيتشير: [مثلاً: إضافة مهمة جديدة]
نقطة البداية: [أيقونة التطبيق / شاشة Home داخل التطبيق]
نقطة النهاية: [المهمة تظهر في القائمة]
المدة المستهدفة: [20-40 ثانية]

بعد التصوير:
1) راجع الفيديو بنفسك عبر videoReview
2) استخرج الخطوات بقالب templates/steps-from-video.md
3) إذا الفيديو ناقص، أعد التصوير
```

## طلب استخراج خطوات من فيديو موجود

```text
استخدم skill: iphone-mobile-video-agent

هذا مسار الفيديو: [path]
راجعه بصرياً بدقة، وبعدين اكتب الخطوات الكاملة
مع الزمن التقريبي لكل خطوة.
```

## طلب شرح Shortcuts / Automation

```text
استخدم skill: iphone-mobile-video-agent واقرأ docs/iphone/

أبي أشرح/أصمم:
- [ ] Shortcut يدوي
- [ ] Personal Automation (التريغر: _____)
- [ ] App Intent / App Shortcut للمطورين

هدف المستخدم النهائي: [...]
اكتب الخطوات + اقتراح سيناريو فيديو قصير.
```
