# كيف يشتغل الآيفون (للوكيل والمطور)

مرجع عملي يفهم منه الوكيل سلوك الآيفون قبل ما يصوّر فيديو أو يشرح تدفق.

## 1) الصورة الكبيرة

الآيفون جهاز iOS محسّن للمس، مع:

- **Home Screen / SpringBoard**: يدير الأيقونات، App Switcher، Control Center، Notification Center
- **Apps**: كل تطبيق في sandbox معزول
- **System services**: Siri، Spotlight، Shortcuts، Widgets، Focus، Privacy prompts
- **Hardware inputs**: Touch، Face ID / Touch ID، Action Button (في الموديلات الحديثة)، NFC، Apple Pencil (مع iPad غالباً)

الفيديو الجيد للتطبيق لازم يوري:

1. سياق النظام (أيقونة / فتح التطبيق)
2. داخل التطبيق (الشاشات والتفاعل)
3. أي تكامل نظام (Shortcuts، إشعار، ويدجت، Share Sheet)

## 2) دورة حياة التطبيق (مهم للتصوير)

| الحالة | ماذا يحدث | أثر على الفيديو |
|--------|-----------|-----------------|
| Cold start | التطبيق ينفتح من الصفر | أطول، قد يظهر splash |
| Warm start | من App Switcher | أسرع، نفس الحالة السابقة |
| Background | النظام يعلّق العمل | قد تفقد حالة مؤقتة |
| Permission prompt | نظام iOS يعرض حوار | لازم تصوّره إذا جزء من التدفق |

**قاعدة تصوير:** حدّد هل الفيديو يبدأ من أيقونة Home Screen أو من داخل شاشة معيّنة.

## 3) الإيماءات الأساسية

عند كتابة الخطوات من فيديو، استخدم مصطلحات دقيقة:

- **Tap** — ضغطة واحدة
- **Long press** — ضغطة مطوّلة (قوائم السياق، إعادة ترتيب)
- **Swipe** — سحب أفقي/عمودي (تبويبات، حذف، الرجوع من الحافة)
- **Scroll** — تمرير قائمة
- **Pinch** — تكبير/تصغير
- **Type** — كتابة في لوحة المفاتيح
- **Drag** — سحب عنصر لمكان آخر

إيماءات النظام:

- **Swipe up** من الأسفل → Home / App Switcher
- **Swipe down** من الزاوية اليمنى أعلى → Control Center
- **Swipe down** من الوسط أعلى → Notification Center
- **Edge swipe** من اليسار → رجوع (في كثير من التطبيقات)

## 4) الأذونات والخصوصية

iOS يطلب إذن صريح لـ:

- الكاميرا، الميكروفون، الصور
- الموقع (While Using / Always)
- الإشعارات
- تتبع التطبيقات (ATT)
- جهات الاتصال، التقويم، التذكيرات
- Bluetooth، الشبكة المحلية

في الفيديو: إذا التدفق يحتاج إذن، صوّر قبول/رفض الحوار — لا تتخطاه بصمت.

## 5) نقاط الدخول الشائعة للتطبيق

غير فتح الأيقونة، التطبيق ممكن ينفتح من:

| المدخل | متى يظهر في الفيديو |
|--------|---------------------|
| Push notification | المستخدم يضغط الإشعار |
| Widget / Control | من Home Screen أو Control Center |
| Spotlight / Siri | بحث أو أمر صوتي |
| Shortcuts | تشغيل اختصار أو أتمتة |
| Universal Link / Deep Link | رابط يفتح شاشة داخلية |
| Share Sheet | مشاركة من تطبيق آخر |
| Action Button | زر الإجراء في الموديلات المدعومة |
| Live Activity / Dynamic Island | تفاعل سريع من الجزيرة |

إذا فيديوك يشرح تكامل نظام، ابدأ من المدخل مو من داخل التطبيق فقط.

## 6) مقاسات الشاشة وتسجيل الشاشة

- سجّل بوضع **Portrait** افتراضياً لتطبيقات الموبايل
- تجنّب قص حواف الـ Safe Area (Dynamic Island / home indicator)
- النص لازم يكون مقروء؛ لا تصوّر بسرعة تخفي النصوص
- فعّل **Do Not Disturb / Focus** أثناء التصوير لتقليل إشعارات دخيلة
- استخدم حساب ديمو ببيانات وهمية واضحة

## 7) ماذا يهم الوكيل عند المراجعة

اسأل دائماً:

1. هل شاشتنا الأولى تطابق الـ brief؟
2. هل كل Tap واضح مكانه (زر/خلية/أيقونة)؟
3. هل فيه قفزة زمنية تخفي خطوة؟
4. هل النتيجة النهائية ظاهرة أقل من ثانيتين في النهاية؟
5. هل ظهر أي alert نظامي وما تم ذكره في الخطوات؟
