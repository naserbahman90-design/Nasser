# تطبيق Shortcuts على الآيفون

Shortcuts هو تطبيق أبل لبناء **اختصارات**: سلسلة أفعال (actions) تنفَّذ بضغطة، من Siri، من ويدجت، أو من Share Sheet.

## 1) المفاهيم الأساسية

| المصطلح | المعنى |
|---------|--------|
| **Shortcut** | سير عمل مكوّن من أفعال مرتبة |
| **Action** | خطوة واحدة (فتح تطبيق، إرسال رسالة، جلب محتوى، متغير…) |
| **Variable** | قيمة تنتقل بين الأفعال |
| **Personal Automation** | اختصار يشتغل تلقائياً عند تريغر (انظر `03-automation.md`) |
| **App Shortcut** | اختصار جاهز يوفّره المطوّر مع التطبيق |
| **Share Sheet** | تشغيل الاختصار على المحتوى المُشارَك |

## 2) كيف يشغّل المستخدم اختصاراً

1. من تطبيق **Shortcuts** → تبويب Shortcuts
2. من **ويدجت** الشاشة الرئيسية
3. من **Siri** بالاسم أو بعبارة App Shortcut
4. من **Spotlight**
5. من **Share Sheet** داخل تطبيق آخر
6. من **Back Tap** / **Action Button** (إن تم تعيينه)
7. من **أتمتة** عند حدوث تريغر

للتصوير: وضّح في الـ brief من أي مدخل يبدأ المستخدم.

## 3) بناء اختصار (خطوات عملية)

1. افتح Shortcuts → `+`
2. أضف اسم واضح
3. `Add Action` → ابحث بالفئة أو اسم التطبيق
4. رتّب الأفعال بالسحب
5. اربط المخرجات بالمتغيرات عند الحاجة
6. اختبر بـ ▶
7. (اختياري) أضف للشاشة الرئيسية / Siri / Share Sheet

### نصائح جودة

- اسم الاختصار = فعل واضح: «أضف مهمة سريعة» مو «اختصار 1»
- قلّل عدد الأفعال؛ كل فعل لازم يخدم الهدف
- استخدم Ask for Input فقط إذا القيمة لازم من المستخدم
- وفّر رسالة نجاح قصيرة في النهاية إذا النتيجة مو مرئية

## 4) أنواع الأفعال الشائعة

### نظام iOS

- Open App / Open URL
- Set Focus / Set Brightness / Set Low Power Mode
- Show Notification / Show Result
- Get Current Location / Get Contents of URL
- If / Repeat / Wait / Choose from Menu

### تطبيقات الطرف الثالث

تظهر فقط إذا المطوّر وفّر **App Intents** (أو Intents قديمة).  
بدون دعم المطوّر، ما تقدر تعمل إلا فتح التطبيق أو روابط عميقة محدودة.

### سكربتات وويب

- Run JavaScript on Web Page (من Share Sheet في Safari)
- Get Contents of URL + Get Dictionary from Input
- Base64 Encode، ملفات، حافظة

## 5) App Shortcuts (من جهة المطوّر)

لما التطبيق يعرّف `AppShortcutsProvider`:

- تظهر الاختصارات **فور التثبيت** بدون إعداد يدوي
- تدعم عبارات Siri فيها `applicationName`
- تظهر في قسم التطبيق داخل Shortcuts
- مناسبة للأفعال المحورية فقط (حد أقصى حوالي 10)

فرق مهم للوكيل:

- **Shortcut يدوي** = المستخدم يبنيه
- **App Shortcut** = المطوّر يجهّزه في الكود

## 6) أفضل ممارسات لفيديوهات Shortcuts

صوّر بهذا الترتيب غالباً:

1. شاشة Shortcuts (أو Siri / ويدجت حسب المدخل)
2. تشغيل الاختصار
3. أي حوار إذن أو Ask for Input
4. نتيجة واضحة داخل التطبيق أو إشعار/نتيجة النظام

عند استخراج الخطوات، اذكر:

- اسم الاختصار
- المدخل (Siri / ويدجت / التطبيق)
- كل Action ظاهر إذا كنت تعلّم البناء، أو فقط نتيجة التشغيل إذا كنت تعلّم الاستخدام

## 7) قيود مهمة

- بعض الأفعال تحتاج التطبيق مفتوحاً في المقدمة
- الأذونات تنطبق على الاختصار كما على التطبيق
- الأتمتة الشخصية **لا تتزامن** بين الأجهزة (backup فقط)
- ليس كل تطبيق يظهر أفعالاً غنية في Shortcuts
